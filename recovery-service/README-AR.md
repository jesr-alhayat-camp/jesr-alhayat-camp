# تفعيل حساب الأسرة لأول مرة

الحزمة تعمل مع aljalacamp-test. التفعيل لأول مرة يبدأ بإدخال هوية رب الأسرة ثم مطابقة هوية إحدى الزوجات المسجّلات، عدد أفراد الأسرة وآخر سبعة أرقام من الجوال الأول. بعد مطابقة الإجابات تفتح شاشة إنشاء كلمة المرور مباشرة. إذا كان حساب Firebase موجودًا من قبل، يبقى حسابه وكلمة مروره كما هما. زر «نسيت كلمة المرور؟» يفتح صفحة التواصل مع الإدارة.

## التشغيل والربط

1. جهّز استضافة Node بعنوان HTTPS مستقل لخدمة التفعيل. احفظ اعتماد Firebase Admin SDK لمشروع aljalacamp-test في إعدادات الأسرار الخاصة بالخدمة، واستخدم GOOGLE_APPLICATION_CREDENTIALS أو اعتماد التطبيق الافتراضي في بيئة الاستضافة.
2. اضبط CAMP_RECOVERY_SECRET على قيمة عشوائية ثابتة بطول 32 بايت على الأقل. تغييرها يبطل الجلسات والعدادات الحالية.
3. داخل recovery-service شغّل npm install --no-save --package-lock=false firebase-admin، ثم node start.cjs. اضبط HOST وPORT حسب مزوّد الاستضافة.
4. في public/assets/camp-recovery-config.js أدخل عنوان HTTPS للخدمة. ارفع Hosting فقط بالأمر firebase deploy --only hosting --project aljalacamp-test.
5. جرّب على سجلات وهمية مستوردة ومزامنة قبل الاستخدام على بيانات حقيقية. اختبر ثلاث إجابات خاطئة، تعيين كلمة المرور لأول حساب، إعادة محاولة التفعيل للحساب نفسه، الدخول بكلمة المرور الجديدة وزر التواصل.

تبقى الإجابات المطابقة داخل الخدمة، والإجابات المدخلة لا تُخزّن. عدّاد المحاولات يُحدّث بمعاملة Firebase، وتُغلق المحاولة بعد ثلاثة أخطاء خلال 30 دقيقة. فتح صفحة كلمة المرور مرتبط بجلسة التحقق نفسها لمدة 10 دقائق. الأسر اللي ما عندها هوية زوجة أو بيانات مطابقة تتواصل مع الإدارة. خدمة التفعيل ما فيها عملية لتغيير أو إعادة تعيين كلمة مرور حساب موجود.

## تشغيل خدمة حسابات جسر الحياة

مجلد خدمة Node هو `recovery-service`. التثبيت بالأمر `npm ci --omit=dev` والتشغيل بالأمر `npm start`. فحص بدء التشغيل على `/healthz`. الإعدادات التالية خاصة بمشروع جسر الحياة:

- `CAMP_FIREBASE_PROJECT=alhayacamp-a31eb`
- `HOST=0.0.0.0`
- `GOOGLE_APPLICATION_CREDENTIALS=/etc/secrets/firebase-admin.json` مع اعتماد حساب الخدمة الخاص بجسر الحياة في Secret Files.
- `CAMP_FIREBASE_WEB_API_KEY` من إعدادات تطبيق الويب لجسر الحياة.
- `CAMP_PUBLIC_SERVICE_URL` عنوان HTTPS النهائي لخدمة الحسابات.
- `CAMP_RECOVERY_SECRET` قيمة عشوائية ثابتة، طولها 32 بايت على الأقل.
- `CAMP_PASSWORD_ENCRYPTION_KEY` مفتاح عشوائي مستقل طوله 32 بايت، ممثل بـ 64 خانة hex. احفظه في إعدادات الخدمة. تغييره يجعل السجلات السابقة غير قابلة للقراءة.

بعد فحص الخدمة، حدّث `public/assets/camp-recovery-config.js` بعنوانها قبل نشر Hosting. اختبار المسارات محلياً بمحاكاة Firebase عبر `node --test *.test.cjs` من مجلد الخدمة. اختبر بعد الربط بعائلتين وهميتين.

كلمات المرور القديمة ما بتنتقل تلقائياً. إعادة التعيين من اللوحة بتحتفظ بحساب الدخول الحالي. دخول المدير لازم يكون حديثاً لعرض كلمة السر أو إصدار رابط. استخدم مسارات الموقع لتغيير كلمات سر العائلات كي تظل نسخة الإظهار متزامنة.
