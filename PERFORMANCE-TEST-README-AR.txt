نسخة قياس أداء تجريبية - aljalacamp-test فقط

ما تغير:
1) قياس زمن قراءة بيانات العائلة من Firebase وإظهاره في Console دون عرض بيانات الأسرة.
2) قياس زمن المزامنة الأولية للوحة الإدارة في Console.
3) الاحتفاظ بقواعد الاختبار المصححة الموجودة في النسخة السابقة.

لم يتغير سلوك الاتصال أو الصلاحيات. هذه نسخة قياس وليست حلاً مثبتاً لتحمل 250 مستخدماً.

طريقة النشر (بعد أخذ نسخة احتياطية):
افتح PowerShell داخل مجلد aljalacamp-site ثم نفذ:
firebase deploy --only hosting --project aljalacamp-test

لا تنشر قواعد قاعدة البيانات ولا تنفذ firebase deploy بدون --only hosting.

الاختبار:
افتح الموقع التجريبي ثم F12 > Console.
ادخل بحساب العائلة الوهمية وسجل زمن Family portal read.
ادخل بحساب المدير وسجل زمن Admin initial data sync.
كرر كل تجربة ثلاث مرات في نافذة خاصة لتقليل تأثير التخزين المؤقت.
لا تستخدم بيانات العائلات الحقيقية ولا تشارك كلمات المرور أو رموز الدخول.

ملاحظة: ملف portal التجريبي الحالي يتوقع مصفوفة row لبيانات العائلة؛ بيانات العائلة الوهمية المختصرة قد لا تظهر تفاصيل كاملة.
