# بيئة اختبار منفصلة — مخيم الأصدقاء الجلاء

**تحذير:** هذه النسخة ليست للنشر مباشرة. جميع إعدادات Firebase الإنتاجية أزيلت عمدًا. قواعد قاعدة البيانات التجريبية الافتراضية تمنع القراءة والكتابة إلى حين إعداد قواعد اختبار مناسبة.

## إعداد مشروع Firebase تجريبي
1. أنشئ مشروع Firebase **جديدًا منفصلًا** من Firebase Console، ولا تستخدم `aljalacamp`.
2. أضف Web App وفعّل Authentication (Email/Password) وRealtime Database في المشروع التجريبي فقط.
3. انسخ إعدادات Web App التجريبية إلى مواضع `REPLACE_WITH_TEST_...` في `public/assets/portal-r3.js` و`public/assets/admin-r3.js`، مع التأكد أن `databaseURL` هو رابط قاعدة الاختبار الحقيقي. لا تضع بيانات العائلات الفعلية.
4. غيّر `REPLACE_WITH_TEST_PROJECT_ID` في `.firebaserc` إلى معرف المشروع التجريبي.
5. اختبر أولًا محليًا باستخدام Firebase Emulator Suite؛ يتطلب Node.js وJava وFirebase CLI: `npm install -g firebase-tools` ثم `firebase emulators:start` داخل `aljalacamp-site`.
6. قبل تجربة تسجيل الدخول فعليًا، يجب تهيئة قواعد أمان اختبارية مناسبة وبناء حسابات وهمية، لأن `database.rules.json` الحالي يغلق الوصول افتراضيًا. لا تنسخ قواعد الإنتاج أو بياناته دون مراجعة.
7. عند النشر على المشروع التجريبي، تحقّق من المعرّف يدويًا واستعمل `firebase deploy --only hosting --project YOUR_TEST_PROJECT_ID`، **ولا تستخدم** معرف المشروع الإنتاجي. لا تنشر قواعد قاعدة البيانات الافتراضية عن غير قصد.

## خطة قياس الأداء
- 5 ثم 25 ثم 50 مستخدمًا وهميًا في Emulator، ثم اختبارات محدودة على مشروع تجريبي حقيقي.
- سجّل نسبة نجاح الدخول، زمن فتح البوابة (الوسيط وP95)، حجم البيانات، أخطاء الصلاحيات، وعدد اتصالات RTDB.
- لا تشغّل اختبار 250 حسابًا في ثانية واحدة على Authentication الحقيقي؛ قد تتدخل قيود إساءة الاستخدام. استخدم توزيعًا تدريجيًا، وبيانات وحسابات وهمية.
- Spark محدود في الاتصالات المتزامنة بـ100 اتصال RTDB. لا يمكن ضمان 250 اتصالًا مباشرًا؛ الاختبار يحدد حدود التشغيل الفعلية فقط.

## قائمة فحص
- [ ] لا توجد أي إعدادات اتصال بقاعدة الإنتاج في النسخة التجريبية
- [ ] دخول العائلة الوهمية وقراءة `portal/{id}`
- [ ] إنشاء طلب وهمي في `inbox/{id}` دون وصول لعائلة أخرى
- [ ] صلاحيات المدير التجريبي
- [ ] تصفح لوحة الإدارة، الكشوفات، الفلترة، والتصدير
- [ ] تجربة المتصفح Chrome على جهاز متأثر
- [ ] توثيق القياسات قبل التفكير في النشر

**الحالة:** إعداد حزمة اختبار فقط؛ لم يُنشأ مشروع Firebase خارجي ولم تُجرَ اختبارات تحميل حقيقية.

## ربط المشروع
تم إدخال إعدادات تطبيق الويب التجريبي `aljalacamp-test` في ملفات البوابة والإدارة. قواعد قاعدة البيانات ما زالت مغلقة؛ لا تنشر أو تختبر تسجيل الدخول قبل إعداد قواعد وحسابات اختبار وهمية. لم يُنفّذ أي نشر أو اختبار ضغط فعلي.
